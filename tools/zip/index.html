Everything happens in your browser — nothing is uploaded. Every level makes an ordinary zip that Windows, macOS, Android, iOS and Linux open without extra apps, and it's lossless: before you can download it, each file is unzipped again and checked against the original. MAX uses Zopfli, which searches far harder for the smallest standard zip and is much slower. Files that are already compressed (photos, video, music, other archives) barely shrink at any level, and are stored as they are whenever compressing wouldn't help.
